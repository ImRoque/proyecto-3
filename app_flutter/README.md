# app_flutter

**Propósito:** aplicación Flutter única que se ejecutará en navegador y en Android con el mismo código.

**Responsable:** _pendiente de asignar por el equipo_

## Contenido previsto (pendiente de acuerdo)

- Proyecto Flutter (`flutter create`)
- Pantallas: catálogo, recomendación, pedido y consulta por folio, asistente
- URL base configurable por plataforma
- Build web y APK documentados

Nota: cuando se cree el proyecto, **`pubspec.lock` se debe versionar**.
